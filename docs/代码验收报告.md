## 发现并修复的问题

1. 客户端和服务端的字段名、签名字节与离线宽限语义最初不一致；已统一为 canonical JSON UTF-8 + Ed25519，终身授权使用 `expiresAt: null`，离线宽限独立计算。
2. 激活成功后首次运行不会自动启动监控；已补上启动和 Cookie 恢复。
3. 用户提前关闭网页登录窗口可能一直等待超时；已增加关闭事件处理。
4. 原打包路径逻辑会在每次启动时覆盖用户配置；已改为保留可变配置，只刷新随版本发布的只读配置。
5. 自有版本接口字段与原更新器预期不同；已增加服务端字段适配和版本比较。
6. License Server 构建产物原位于 `dist/src/main.js`，启动脚本却读取 `dist/main.js`；已收紧 TypeScript 编译范围并固定源码根目录，使本机与容器启动入口一致。
